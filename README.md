## Project Description

This Weather App was built using HTML, CSS, and JavaScript. The application allows users to search for any city in the world and view real-time weather information along with a 5-day forecast. The project uses the Open-Meteo Geocoding API to convert city names into geographical coordinates and the Open-Meteo Weather API to retrieve current weather conditions and forecast data. JavaScript Fetch API with async/await was used to handle API requests, while DOM manipulation was used to dynamically update the user interface. The application includes responsive design, error handling, loading states, and weather code mapping to display weather descriptions and icons.

## Features

- Search weather by city name
- Display city and country information
- Display current temperature in °C
- Display weather description and icon
- Display humidity percentage
- Display wind speed in km/h
- Display UV Index
- Display 5-day weather forecast
- Loading state while fetching data
- Error handling for invalid city names
- Responsive design for desktop and mobile devices
